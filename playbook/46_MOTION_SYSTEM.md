# F.I. Forgot Motion System

---

# Purpose

Motion is part of the user experience.

It communicates.

It reassures.

It guides.

It never exists simply because animation is possible.

Every movement should reinforce the feeling that a thoughtful Relationship Concierge is quietly helping in the background.

Users should rarely notice the animations themselves.

They should simply feel that the application is smooth, polished, and alive.

---

# Motion Philosophy

Motion should feel:

* Calm

* Natural

* Purposeful

* Predictable

* Elegant

* Fast

* Unobtrusive

Animation should never become entertainment.

It should always support understanding.

---

# Emotional Goals

Motion should help users feel:

Safe.

Confident.

In control.

Comfortable.

Never rushed.

Never distracted.

Never overwhelmed.

---

# Core Principles

## Motion Explains

Animation should explain:

Where content came from.

Where content went.

What changed.

Why something happened.

---

## Motion Should Never Surprise

Unexpected movement creates anxiety.

Users should always understand why something moved.

---

## Faster Is Usually Better

Animations should finish quickly.

Slow animations make software feel slower.

Long transitions create frustration.

---

## Motion Should Feel Physical

Elements should behave naturally.

Heavy objects should feel heavier.

Small elements should move quickly.

Large surfaces should move more gently.

---

## Every Animation Needs A Reason

If removing an animation improves the experience, remove it.

Motion is never decorative.

---

# Timing Philosophy

Motion should feel immediate.

Recommended timing categories:

Instant

Fast

Normal

Slow

Extra Slow

Most interactions should use Fast or Normal.

Very few interactions should use Slow.

Nothing should ever feel delayed.

---

# Easing Philosophy

Motion should accelerate naturally.

Movement should never start or stop abruptly.

Preferred easing:

Ease Out

Ease In Out

Gentle Spring

Avoid:

Linear movement.

Elastic movement.

Bounce effects.

Overshoot animations.

---

# Page Transitions

Page transitions should reinforce orientation.

Pages should gently fade while moving a small distance.

Users should always understand:

"I've gone somewhere new."

Transitions should never feel cinematic.

---

# Navigation Transitions

Navigation should feel effortless.

Changing sections should be nearly instant.

Sidebars should slide naturally.

Tab changes should feel immediate.

Never animate entire layouts unnecessarily.

---

# Screen Loading

Loading should reassure users.

Prefer skeleton screens.

Avoid blank white screens.

Avoid spinning loaders whenever possible.

Users should always feel:

"The application is working."

---

# Skeleton Loading

Skeletons should match the final layout.

Never use generic placeholders.

Cards should resemble cards.

Avatars should resemble avatars.

Timeline placeholders should resemble timeline entries.

The transition from skeleton to content should feel seamless.

---

# Dashboard Motion

The dashboard should appear gently.

Hero content appears first.

Upcoming moments follow.

Supporting sections appear afterward.

Never animate every card independently.

Avoid excessive stagger effects.

---

# Relationship Page Motion

Relationship pages should feel like opening a scrapbook.

Timeline entries gently appear.

Photos softly fade into view.

Memories expand naturally.

Scrolling should remain fluid.

---

# Timeline Animation

Timeline items should appear chronologically.

New memories should gently insert themselves into the timeline.

Nothing should jump unexpectedly.

The timeline should feel alive without becoming distracting.

---

# Card Animations

Cards should communicate hierarchy.

Hover:

Slight elevation.

Very subtle shadow increase.

No dramatic movement.

Selection:

Gentle emphasis.

Never dramatic scaling.

Expansion:

Smooth height transition.

Content fades naturally.

---

# Button Motion

Buttons should feel responsive.

Hover:

Subtle.

Press:

Immediate.

Release:

Natural.

Loading:

Content changes smoothly.

Never rotate the entire button.

---

# Input Motion

Inputs should communicate focus.

Focus:

Border transitions smoothly.

Label moves naturally if floating labels exist.

Validation:

Gentle color transition.

Small icon animation if appropriate.

Never shake excessively.

---

# Form Progress

Multi step forms should feel continuous.

Progress indicators update naturally.

Sections slide or fade gently.

Users should always know where they are.

---

# Modal Motion

Modals should feel like layered surfaces.

Background gently dims.

Modal fades while moving slightly upward.

Closing reverses naturally.

Never zoom dramatically.

Never spin.

---

# Drawer Motion

Drawers should slide naturally from their edge.

Content behind the drawer should remain stable.

Drawers should never bounce.

---

# Toast Notifications

Toasts should appear quietly.

Slide slightly.

Fade naturally.

Disappear automatically.

Never interrupt the user's work.

---

# Success Animations

Success should feel satisfying.

Examples:

Memory saved.

Card created.

Relationship updated.

Subscription changed.

Animation should be subtle.

Never celebratory unless appropriate.

---

# Error Animations

Errors should feel calm.

Gentle color transition.

Small icon appearance.

Helpful explanation.

Avoid aggressive shaking.

Avoid flashing.

Avoid blinking.

---

# Empty States

Illustrations should gently appear.

Primary action should become visible naturally.

Empty states should feel inviting.

Not lonely.

---

# AI Thinking States

AI should never pretend to think.

Instead, communicate useful progress.

Examples:

Gathering your memories...

Looking through previous cards...

Building a first draft...

Finding meaningful details...

Progress indicators should feel informative.

Not theatrical.

---

# Concierge Moments

When the concierge offers guidance, motion should feel personal.

Suggestion cards may gently fade into view.

Helpful prompts should appear naturally.

Nothing should pop into existence unexpectedly.

---

# Notification Center

New notifications should quietly appear.

Unread indicators fade in.

Dismissal should feel lightweight.

Never animate the entire notification list.

---

# Search

Search results should appear immediately.

Filtering should avoid large layout shifts.

Empty search results should fade naturally.

Typing should never lag because of animation.

---

# Accordions

Expansion should reveal content smoothly.

Collapse should never snap closed.

Users should maintain visual context.

---

# Tabs

Switching tabs should feel instant.

A small indicator movement is sufficient.

Avoid sliding entire pages.

---

# Hover States

Desktop hover effects should be restrained.

Slight elevation.

Subtle color adjustment.

Soft shadow.

Never dramatic scaling.

Never glowing effects.

---

# Focus States

Keyboard focus should animate smoothly.

Focus rings should appear immediately.

Never hide focus.

Accessibility always comes first.

---

# Scrolling

Scrolling should remain native.

Avoid scroll hijacking.

Avoid artificial momentum.

Users should stay in control.

---

# Pull To Refresh

Mobile refresh interactions should feel lightweight.

Clear progress.

Natural completion.

No unnecessary animations.

---

# Drag And Drop

Dragged items should follow the pointer naturally.

Drop targets gently highlight.

Dropped items settle smoothly.

Never bounce.

---

# Card Creation Experience

While writing cards:

Avoid distracting animations.

Cursor movement should feel immediate.

Suggestions should appear naturally.

Editing should remain uninterrupted.

The writing experience should feel peaceful.

---

# Business Experience

Business users often move quickly.

Animations should become even more subtle.

Prioritize speed over visual flourish.

---

# Accessibility

Users who prefer reduced motion must receive it.

Support operating system motion preferences.

Reduce:

Page transitions.

Parallax.

Sliding.

Scaling.

Preserve:

Focus indicators.

State changes.

Meaningful feedback.

Accessibility always overrides visual preference.

---

# Performance Rules

Animation must never reduce responsiveness.

Maintain smooth frame rates.

Avoid expensive layout calculations.

Prefer transforms over layout changes.

Avoid unnecessary repainting.

Performance is part of the design.

---

# Things To Avoid

Avoid bouncing.

Avoid spinning.

Avoid elastic effects.

Avoid parallax.

Avoid confetti.

Avoid fireworks.

Avoid exaggerated success celebrations.

Avoid loading animations that feel theatrical.

Avoid flashy hover effects.

Avoid floating interface elements.

Avoid unpredictable movement.

Avoid delayed interactions.

Avoid animation for decoration.

---

# Motion Consistency Checklist

Before shipping any animation:

Does it communicate something useful?

Does it improve understanding?

Is it subtle?

Is it fast?

Does it respect accessibility settings?

Would removing it make the experience worse?

Does it feel calm?

Does it reinforce trust?

Would a luxury concierge product move this way?

If not, redesign it.

---

# Final Principle

The best motion is the motion users barely notice.

It quietly explains.

It gently reassures.

It never distracts from the people who matter.

When users remember F.I. Forgot, they should remember the relationships they strengthened, not the animations they watched.

That is the motion system of F.I. Forgot.
