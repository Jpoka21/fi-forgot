# Color System

---

# Purpose

The F.I. Forgot color system exists to create emotional consistency across the entire product.

Our colors are not selected simply because they look attractive.

They exist to reinforce trust, warmth, calmness, premium quality, and genuine human connection.

Every color should make the product feel less like software and more like a thoughtful concierge quietly helping someone become better at maintaining meaningful relationships.

Color should never distract.

Color should guide.

Color should reassure.

Color should support the experience rather than compete with it.

Every color decision should answer one question:

> **"Does this help the user feel more thoughtful, more confident, and more cared for?"**

---

# Color Philosophy

Most software products rely on bright, saturated colors to create excitement.

F.I. Forgot does the opposite.

This product should feel calm.

Luxury hotels.

Premium stationery.

High quality journals.

Beautiful hardcover books.

Warm natural materials.

Soft morning light.

Handwritten letters.

Comfortable living rooms.

Fresh paper.

Natural wood.

Quiet confidence.

The interface should never feel loud.

Instead it should feel welcoming, emotionally intelligent, and timeless.

Color should disappear into the experience.

Relationships remain the hero.

---

The color system should consistently communicate:

## Warmth

The product should feel human.

Never cold.

Never sterile.

Never corporate.

---

## Trust

Users are sharing deeply personal stories.

The interface must immediately communicate safety.

---

## Calm

Nothing should create anxiety.

Notifications.

Warnings.

Calls to action.

Everything should feel gentle.

---

## Premium Quality

The experience should feel handcrafted.

Not flashy.

Not trendy.

Not disposable.

---

## Optimism

Relationships improve over time.

The product should always feel hopeful.

Even difficult moments should feel encouraging rather than discouraging.

Dark dramatic gradients

Tech gradients

# Review Checklist

Before approving any screen, verify:

□ Does the interface feel warm?

□ Does it feel premium?

□ Does it feel calm?

□ Is Concierge Red used sparingly?

□ Is typography doing most of the work?

□ Are semantic colors used only for meaning?

□ Are backgrounds soft and inviting?

□ Are borders subtle?

□ Are interactions accessible?

□ Are all text contrast ratios compliant?

□ Is there enough white space?

□ Does the interface avoid visual noise?

□ Does color guide rather than decorate?

□ Does the screen feel timeless instead of trendy?

□ Would this feel appropriate for preserving someone's most meaningful relationships?

If the answer to any question is no, the color system should be revised before implementation.
