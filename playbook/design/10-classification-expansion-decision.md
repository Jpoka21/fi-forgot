The Design Library classification system answers one governing question for every planned standard:

## 3. Background

### 3.1 Classification freeze posture

`FI-DSN-CLS-001` Version 1.0 Frozen (July 22, 2026) established **eighteen** primary `CLS-*` codes grouped into six families. New `CLS-*` codes REQUIRE revision to `FI-DSN-CLS-001` before use (CLS-001 §6). Classification assignment SHALL precede Standard ID reservation (CLS-001 §15; REG-001 §7.3).

### 3.2 Volume 06 posture

Volume 06 Creative Production Architecture reached Version 1.0 Frozen on July 29, 2026. Layer B planning is authorized. Four Required Layer B standards are identified in the Volume 06 Layer B Planning Report. Identifier reservation is blocked until each standard has exactly one valid Primary Classification from the frozen taxonomy — or until the taxonomy is lawfully expanded.

### 3.3 Open question trigger

`OQ-V06-002` asks what Primary Classification should govern Volume 06 standards — extend `CLS-ART`, distribute by domain, authorize new classification through governed `FI-DSN-CLS-001` revision, or another alternative. Volume 06 Classification Decision Review (July 29, 2026) concluded that existing codes cannot correctly represent the Volume 06 principal subject without misassignment.

### 3.4 Why a separate decision document

Taxonomy expansion affects every future planning record, register row, queue filter, and freeze review touching Volume 06. `FI-DSN-CLS-001` owns the taxonomy itself. This document owns the **decision record** — why expansion is or is not justified — so that a subsequent CLS-001 amendment proceeds from an auditable constitutional basis rather than ad hoc register edits (CLS-001 §17 prohibited practice: creating `CLS-*` ad hoc in REG without strategy revision).

## 11. Decision

### 11.1 Formal decision (Version 1.0 Frozen)

**The Design Library SHOULD expand from eighteen constitutional classification families to nineteen by creating a new classification family for Creative Production Realization.**

### 11.2 Decision basis

1. **Genuine novel subject:** Volume 06 owns governed visual artifact **realization transformation** — a lifecycle and Decision-policy domain absent from the frozen taxonomy at CLS-001 Version 1.0 freeze.
2. **Existing codes insufficient:** Alternatives B and C fail principal-subject purity; CP-01 has no valid frozen primary; CP-02 through CP-04 require stretch misassignment under ART, VQA, MFI, ASG, or BVS.
3. **Not mere composition:** Volume 06 consumes upstream classified subjects but legislates transformation policy no existing code owns.
4. **Precedent:** `CLS-BVS` and `CLS-ASG` were introduced when novel volume-scoped subjects could not be represented without misassignment — the same structural condition applies to Volume 06.
5. **Exceptional growth only:** One code increment; decision recorded before taxonomy amendment; no register improvisation.

| Introduce a `CLS-*` code string | **Not authorized by this document** |
| Define new classification scope text | **Deferred to CLS-001 Version 1.1** |

| Close `OQ-V06-002` | **Deferred until CLS-001 Version 1.1 freeze** |
