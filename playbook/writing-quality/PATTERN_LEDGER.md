# Pattern Ledger — Recurring Writing Issues & Strengths

**Purpose:** Catalog recurring writing patterns across the golden set so Sprint 9B is driven by frequency × severity, not anecdotes.  
**Update cadence:** After each scored batch (pilot 9A.2, then each 9B retest).  
**Fixed in sprint:** Leave blank until a deliberate writing change lands; then note sprint id (e.g. 9B.1).

Severity guide: **S1** blocks ship · **S2** frequent quality drag · **S3** polish · **P** positive keep.

## How to update frequency

After pilot scoring:

1. Count tag occurrences across all scored rows.  
2. Write count + rate (e.g. `4/20 = 20%`) in **Frequency (pilot)**.  
3. Sort by `severity × weight(severity)` for 9B candidates.  
4. Do not invent new IDs mid-pilot without logging them here first.
