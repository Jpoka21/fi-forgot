Sprint 7 — Grounded Writing Audit & Implementation Plan

Critical issue discovered during real user testing.

When recipient context is sparse, the system frequently invents relationship details, memories, personality traits, hobbies, traditions, and shared experiences.

Examples generated by the system:

* "Remember our road trips to nowhere..."
* "Those all-night gaming marathons..."
* "You make everyone around you feel valued..."
* "Your kindness, humor, and unwavering support..."
* "You make the perfect cup of coffee..."
* "You're the magic in our family's chaos..."

None of these details were provided by the user.

This is not a generic-writing problem.

This is a trust problem.

Users will forgive a simple card.

Users will not forgive a card that invents memories that never happened.

Goal

Create a Grounded Writing Framework.

The AI should distinguish between:

1. User-provided facts
2. Reasonable inferences
3. Prohibited fabrications

Part 1 — Prompt Audit

Review all generation prompts and relationship rules.

Identify every location where the model is encouraged to:

* "be specific"
* "use vivid details"
* "weave memories"
* "tell stories"
* "personalize"

without requiring evidence.

Show exactly which prompt sections may be causing the model to invent details when context is sparse.

Part 2 — Grounded Writing Framework

Design a framework with three categories:

Category A — User Provided Facts

Examples:

* Sean ran a marathon
* Bobby got promoted
* Sarah loves gardening

These are safe to reference directly.

Category B — Reasonable Inference

Examples:

* Training six months for a marathon suggests commitment.
* Earning a promotion suggests hard work.

These should be allowed.

Category C — Prohibited Fabrication

Examples:

* Invented trips
* Invented conversations
* Invented traditions
* Invented hobbies
* Invented personality traits
* Invented family dynamics
* Invented inside jokes
* Invented relationship history

These should not be generated unless present in context.

Part 3 — Context Confidence Levels

Design writing behavior based on available information.

Low Context

Only:

* name
* relationship
* occasion

Behavior:

* Stay honest
* Stay simple
* Avoid invented specifics

Medium Context

A few profile answers or one recent memory.

Behavior:

* Use provided details
* Allow limited inference

High Context

Rich profile + memories + updates.

Behavior:

* Fully personalized
* Deep memory weaving
* Strong callbacks

The card should become more personal only when evidence supports it.
