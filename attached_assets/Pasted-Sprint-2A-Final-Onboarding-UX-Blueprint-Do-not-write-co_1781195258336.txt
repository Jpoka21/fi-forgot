Sprint 2A: Final Onboarding UX Blueprint

Do not write code.

Do not modify files.

Do not implement anything.

This is the final planning document before onboarding development begins.

The onboarding analysis has already been completed and we have agreed on the following principles:

1. Users should experience value as quickly as possible.
2. The first card draft should appear during onboarding, not after onboarding.
3. Mailing address should be collected after value has been demonstrated.
4. The relationship memory database remains a core strategic asset.
5. Progressive profiling should collect most non-essential information later.
6. The onboarding experience should support both conversion and long-term data quality.

Your task is to create the exact onboarding blueprint that will be built.
