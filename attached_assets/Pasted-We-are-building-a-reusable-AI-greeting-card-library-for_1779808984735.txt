We are building a reusable AI greeting card library for our business card automation platform.

IMPORTANT:
We are NO LONGER generating new card images on customer approval pages.
All AI cards must be generated once, stored in the database, and reused forever.

GOAL:
Create a reusable anniversary and holiday card library system with categories, metadata, storage, rotation logic, and admin management.

==================================================
STEP 1 — DATABASE
==================================================

Create a new database table called:

ai_card_library

Fields:

id
uuid

category
(string)

subcategory
(string)

title
(string)

image_url
(string)

thumbnail_url
(string, optional)

prompt_used
(text)

tags
(json array)

style
(string)

tone
(string)

primary_color
(string)

seasonal
(boolean)

active
(boolean)

times_shown
(integer default 0)

times_selected
(integer default 0)

times_rejected
(integer default 0)

created_at
(timestamp)

==================================================
STEP 3 — IMAGE STYLE RULES
==================================================

ALL generated cards must:

- feel premium
- feel emotionally warm
- be business appropriate
- NOT feel romantic
- NOT mention specific businesses or industries
- NOT include heavy text on the front
- leave room for personalized inside messages
- look realistic and professional
- have variety in style and colors
- avoid looking AI-generated

Mix styles:
- modern minimal
- watercolor
- luxury photography
- illustration
- elegant typography
- cozy lifestyle
- seasonal warmth

==================================================
STEP 4 — STORE EVERYTHING
==================================================

After generation:

1. Upload/store image assets
2. Save every generated card into ai_card_library
3. Save metadata/tags for intelligent future selection

Example tags:
["modern", "blue", "luxury", "warm", "minimal", "professional"]

==================================================
STEP 5 — ADMIN PAGE
==================================================

Create an admin page:

/admin/card-library

Features:

- View all generated cards
- Filter by category
- Filter by tags
- Activate/deactivate cards
- Delete cards
- Regenerate individual cards
- Generate additional cards later
- View performance stats:
  - times shown
  - times selected
  - times rejected

==================================================
STEP 6 — CARD SELECTION LOGIC
==================================================

Customer approval pages should NEVER generate new card images.

Instead:

1. Detect event type
2. Match category/subcategory
3. Select best reusable card from ai_card_library
4. Rotate alternatives when user clicks:
   "Try another card"

Track:
- shown
- selected
- rejected

Over time prioritize high-performing cards.
