Before making any production changes, build three visual prototype concepts only.

Do NOT modify the database.

Do NOT modify APIs.

Do NOT modify existing functionality.

Do NOT remove any existing features.

Do NOT perform a redesign implementation.

This is a visual exploration exercise only.

Goal: Help us compare different UX directions before spending development time and credits.

Create three clickable prototype screens using our existing FiForgot branding, colors, typography, Brownie Points style, and visual language.

Use realistic sample data.

The prototypes should feel polished enough that we can evaluate them as if they were real product screens.

CONCEPT 1: YOUR PEOPLE

Philosophy:

People first.

The user should feel like they are managing relationships, not filling out forms.

Dashboard should include:

Header:
"Good Morning James"

Subheading:
"We got your back."

Primary section:
Upcoming Moments

CONCEPT 2: MEMORY VAULT

Philosophy:

Emotional and relationship focused.

Feels more like a scrapbook or relationship journal.

Dashboard should focus less on events and more on people.

Example sections:

People You Care About

Recent Memories Added

Recent Life Updates

Upcoming Moments

Clicking Steve should feel like opening a living memory profile.

Include:

Memories

Inside Jokes

Recent Updates

Life Events

Upcoming Occasions

Generate Card button

The experience should feel warm, personal, and unique.

Less software.

More relationship focused.

---

CONCEPT 3: ACTION FIRST

Philosophy:

Maximum simplicity.

Built entirely around getting a card generated as fast as possible.

Dashboard should contain:

Generate Card

Add Someone

Upcoming Birthdays

Minimal information density.

Very few decisions.

Very few sections.

Extremely simple.

The goal is for a first time user to understand the product within 10 seconds.
