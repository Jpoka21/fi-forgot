Implement Recipient Health Dashboard V1.

GOAL

Transform FiForgot from a card generation tool into a relationship management assistant.

The dashboard should answer one simple question:

"Who should I spend a few minutes on today?"

The system already knows:

Profile completion
Fresh updates
Follow-up questions
Upcoming events
Card history

Now surface that information in a useful way.

---

NEW DASHBOARD SECTION

Add:

Relationship Health

to the main dashboard.

Position:

Above recent activity.

Below the primary call-to-action area.

This should become the most useful section on the dashboard.

---

RECIPIENT HEALTH SCORE

Create:

recipientHealthScore

Range:

0–100

Recalculate automatically.

---

SCORING MODEL

Profile Complete

0–30 points

Fresh Update Recency

Within 30 days = 30 points

31–90 days = 20 points

91–180 days = 10 points

180+ days = 0 points

Pending Follow Up Questions

No pending follow-ups = 20 points

Has pending follow-up = 10 points

Overdue follow-up = 0 points

Upcoming Event Readiness

Event more than 60 days away = 10 points

Event within 60 days and recent update exists = 10 points

Event within 60 days and no recent update = 0 points

Last Card Activity

Card sent within last year = 10 points

Otherwise = 0 points

Maximum:

100 points

---

QUICK ACTION BUTTON

Each recipient should have:

Click behavior:

If profile incomplete:
Open profile question flow

If follow-up waiting:
Open follow-up question

If update stale:
Open fresh update flow

If event approaching:
Open card preparation flow

Always send the user directly to the highest priority action.

---

PERFORMANCE

Health scores should be cached and recalculated efficiently.

Do not run expensive calculations on every page render.

Use background refresh when possible.

---

MOBILE

Recipient cards should stack cleanly.

Recommended Next Step should remain visible without expanding.

Quick Action button should remain accessible.

---

DESIGN PHILOSOPHY

This is not a CRM.

This is not a sales dashboard.

This is a relationship assistant.

The dashboard should feel like:

Here are the people who matter.

Here's who could use a little attention.

Here's the next best thing to do.

---

SUCCESS CRITERIA

A user can log in and within 10 seconds know:

Who needs attention.

Who is ready for an upcoming card.

Which relationships are thriving.

What action they should take next.

The dashboard becomes the primary reason users return between card events.
