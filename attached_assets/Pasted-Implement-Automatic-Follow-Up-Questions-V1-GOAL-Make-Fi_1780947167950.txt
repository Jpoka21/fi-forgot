Implement Automatic Follow Up Questions V1.

GOAL

Make FiForgot feel like it remembers previous conversations and relationship details over time.

The objective is not to ask random new questions.

The objective is to intelligently revisit meaningful life updates that users previously shared.

Users should feel:

"Wow, FiForgot remembered that."

This should become one of the most memorable product features.

---

NEW CONCEPT

Create:

FollowUpQuestion

A follow up question is generated from an existing Fresh Update.

Example:

Original Update:

"Sarah started pickleball."

60 days later:

"Last time you mentioned Sarah started pickleball. How is that going?"

---

Statuses:

QUESTION ENGINE PRIORITY

Current:

Profile Questions

Fresh Updates

Replace with:

1. Unanswered Profile Questions

2. Due Follow Up Questions

3. Fresh Updates

Follow ups should take priority over Fresh Updates because they continue existing stories.

---

UI PRESENTATION

Follow Up Questions should appear in the existing question card.

Do not create a new screen.

Visual treatment:

Light blue header.

Header:

Follow Up Question

Subtext:

You mentioned this previously. Any updates?

Display original context.

Example:

Previously:

Sarah started pickleball.

Question:

How is that going?

---

ANSWER STORAGE

When answered:

Store as a Fresh Update record.

Do not overwrite original answer.

Do not modify source answer.

The follow up answer becomes new relationship memory.

Mark follow up:

answered

---

EXPIRATION

If a Follow Up Question remains unanswered for 180 days:

Mark:

expired

Do not show again.
